# Elgato Stream Deck Afterburner Monitor Integration

This project integrates an Elgato Stream Deck with an Afterburner monitor to display real-time performance metrics of your hardware.

I decided to make this as I could not find an alternative to something that makes use of afterburner with the Stream deck so I decided to make my own.

This project was made as a concept at first, and then over the course of a weekend I tried to make it (given I had no clue when I would next have time to work on it).

That being said, if you wish to help and contribute to this project, feel free to fork the repository and submit a pull request, as I guarantee that this can be improved further.

I don't have the most experience with GitHub so please be patient with any pull requests.

If you have any questions or need help, feel free to open an issue, I will be happy to help.

Thanks for checking out this project and I hope you find it useful!
